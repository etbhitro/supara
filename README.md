# Супара — панель управления (МВП)

Демо-версия платформы управления центром отдыха: шахматка броней, гости, задачи персонала и три демо-агента (гостевой бот, операции, аналитик).

Открыть: https://etbhitro.github.io/supara/

Все гости, брони и цены в демо вымышленные. Сервера и базы нет: данные хранятся в браузере посетителя.

## Запуск у себя

```bash
cd web
npm install
npm run dev   # http://localhost:3000
```
